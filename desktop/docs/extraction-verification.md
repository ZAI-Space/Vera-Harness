## 交付范围

- `vera-desktop` 有独立的 package.json、锁文件、依赖安装、Electron 入口、preload 和构建配置
- 保留现有聊天界面、通用与行为设置、模型配置、Subagent 模板、沙箱表单、插件和定时任务页面
- 不依赖原项目源码、node_modules 链接或运行中的后端
- 未安装 Pi SDK 或原项目后端包，不包含 SSH 连接、智能体执行或旧发布流程
- 来源许可证保存在 third_party

## 桌面实测

- 关闭原项目预览后，使用新项目内的 Electron 加载 `out/renderer/index.html`
- 渲染页面使用 file URL，原 5173、5180 开发服务和 9224 调试服务未运行
- 名称为 VERA，注入 `window.vera`，`window.pi` 不存在
- 侧栏显示“后端未连接”，发送请求明确返回未连接错误
- 通用、行为、Subagent、模型、Skills、MCP、扩展、跨设备互联与关于页可打开
- 主题切换实际写入独立 UI 偏好，重载后恢复，并恢复跟随系统设置
- 从探索者模板创建 Subagent，保存后重载仍存在，再通过界面删除测试草稿
- 插件与定时任务页面可点击打开
