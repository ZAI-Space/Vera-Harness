# VERA · Runtime configuration / 运行配置

## English

vera.yaml supplies interactive defaults; default.yaml supplies base-agent templates. benchmarks/ contains benchmark-specific overlays. Merge a complete base before task overlays.

See [documentation](../../../docs/index.md) and [frontend interfaces](../../../docs/frontend-integration.md).
