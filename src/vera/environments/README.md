# VERA · Execution environments / 执行环境

## English

local.py runs host commands; docker.py and singularity.py use their configured engines. sandbox.py applies workspace policy; sandbox_profiles.py manages user-configured named environments. Optional extra/ backends require their own dependencies.

See [documentation](../../../docs/index.md) and [frontend interfaces](../../../docs/frontend-integration.md).

## 简体中文

local.py 执行宿主命令，docker.py 与 singularity.py 使用对应引擎；sandbox.py 管工作区策略，sandbox_profiles.py 管具名环境。extra/ 可选后端需单独准备依赖。

参阅[中文文档](../../../docs/zh/index.md)及[前端接口](../../../docs/zh/frontend-integration.md)。
