# VERA · Model adapters / 模型适配器

## English

Choose one configured adapter. Native tool models support registered capabilities; text-action adapters provide Bash-only execution. Models parse actions and format observations. Each registry needs its own adapter instance.

See [documentation](../../../docs/index.md) and [frontend interfaces](../../../docs/frontend-integration.md).

## 简体中文

选择一个配置好的适配器；原生工具模型支持注册能力，文本动作模型为 Bash 路径。模型解析动作和格式化观察，每个注册表需要独立适配器实例。

参阅[中文文档](../../../docs/zh/index.md)及[前端接口](../../../docs/zh/frontend-integration.md)。
