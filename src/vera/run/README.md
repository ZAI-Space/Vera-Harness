# VERA · Entry points / 运行入口

## English

cli.py serves vera and python -m vera. utilities/extra.py serves vera-extra. Shared Runtime owns capability assembly; channels, scheduler and evolution are independent callers.

See [documentation](../../../docs/index.md) and [frontend interfaces](../../../docs/frontend-integration.md).
