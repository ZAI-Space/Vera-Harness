# 安全说明

## 报告问题

通过当前 VERA 仓库可用的维护者联系/安全渠道报告，提供候选版本、脱敏配置、复现步骤和预期边界。不要把 VERA 支持请求发送给上游作者，不公开活跃密钥、用户数据或针对他人服务的攻击细节。

## 执行与数据边界

local 具有当前用户宿主权限，confirm 是审批而非隔离，yolo 是明确免审批。需要隔离时配置沙箱，并单独管理宿主 MCP/网页 opt-in。下载的插件、Skill 和外部服务内容不当作可信宿主指令。

任务、轨迹和设置可能含敏感项目数据；渠道凭据按平台提供其明确保护，其他快照不是通用加密保险箱。数据放私人目录，检查账号范围，不提交 Git。参阅[沙箱](sandbox.md)与[前端边界](frontend-integration.md)。
